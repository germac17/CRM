# Найми

Платформа для умного найма, управления жизненным циклом
сотрудников и развития талантов с использованием графа навыков и
предиктивного матчинга.

## Цели
- Снижение срока закрытия вакансий на 30% в течение 12 месяцев после запуска
- Рост удержания сотрудников на 25% в течение 12 месяцев после запуска

## Объем (MVP)
Включено: база кандидатов/сотрудников, воронка найма, вакансии, автоматические
коммуникации, календарь, ИИ матчинг, управление эффективностью,
онбординг/оффбординг, HR метрики и дашборды, поиск и матчинг, интеграции,
адаптивный интерфейс, API-first, RBAC, аудит и безопасность.

Исключено: живые видеоинтервью, пользовательское обучение моделей, зарплата и
бенефиты, многоязычность.

## Структура репозитория
- `docs/` требования, архитектура и роадмап
- `frontend/` веб-интерфейс (React/Next.js, TypeScript)
- `backend/` API сервисы (Node.js, TypeScript)
- `ai/` ИИ/ML сервисы и пайплайны (Python)
- `infra/` инфраструктура и деплой

## Локальный запуск
### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

### Backend
1. `cd backend`
2. `npm install`
3. `npm run dev`

### ИИ сервис
1. `cd ai`
2. `python -m venv .venv`
3. `.venv\\Scripts\\activate`
4. `pip install -r requirements.txt`
5. `uvicorn app:app --reload --port 8001`
 
## Система ИИ-матчинга (полностью интегрирована)

Полноценная система автоматического подбора кандидатов на основе AI/ML — готова к использованию.

### Возможности
- **Автоматический анализ** резюме и вакансий
- **Оценка 1-10 баллов** с прозрачными объяснениями
- **Категоризация кандидатов**: Подходящие / Условно / Не подходящие
- **NLP обработка**: понимание синонимов и семантики (spaCy + BERT)
- **ML алгоритмы**: TF-IDF + BERT embeddings, cosine similarity
- **Гибкие фильтры**: настраиваемые веса и критерии
- **REST API**: 7 endpoints готовы
- **UI**: интегрировано в CRM с вкладкой «ИИ матчинг»

### Запуск всей системы

```powershell
.\start_all.ps1
```

Скрипт автоматически запускает Backend (4000), AI Service (8001), Frontend (3000) и открывает браузер.

**Альтернатива (вручную):**
```powershell
# Терминал 1: Backend
cd backend && npm run dev

# Терминал 2: AI Service  
cd ai && python app.py

# Терминал 3: Frontend
cd frontend && npm run dev
```

### Как использовать

1. Откройте http://localhost:3000
2. Войдите (admin@crm.ru / admin)
3. Перейдите на вкладку «ИИ матчинг»
4. Выберите вакансию
5. Нажмите «Запустить AI-анализ»
6. Через 5-10 секунд увидите результаты
