## 📊 Компоненты оценки

### 🎯 Навыки (40%)
- **Что оценивается:** Совпадение требуемых навыков
- **Пример:** 5/3 означает "5 навыков кандидата совпали из 3 требуемых"
- **Интерпретация:** Чем больше число, тем лучше
- **Индикатор:** ✓ если все требования выполнены

### 🧠 Семантика (30%)
- **Что оценивается:** Контекстное сходство резюме и вакансии
- **Диапазон:** 0-100%
- **Интерпретация:** 
  - 80-100% - Очень похожи по смыслу
  - 60-79% - Умеренное сходство
  - <60% - Слабое сходство

### 💼 Опыт (20%)
- **Что оценивается:** Соответствие лет опыта требованиям
- **Диапазон:** 0-100%
- **Интерпретация:**
  - 100% - Опыт идеально соответствует
  - 75-99% - Опыт достаточный
  - <75% - Опыт недостаточный

### 🎓 Образование (10%)
- **Что оценивается:** Наличие требуемого образования
- **Значения:** ✓ Да / ✗ Нет
- **Примечание:** Не всегда является критичным фактором

## 🐛 Решение проблем

### Ошибка: "AI сервис вернул ошибку"

**Причина:** AI-сервис не запущен или недоступен

**Решение:**
```powershell
cd ai
python app.py
```

Проверьте: http://localhost:8001/health

### Результаты не отображаются

**Решение:**
1. Откройте DevTools (F12)
2. Проверьте вкладку Console на ошибки
3. Проверьте вкладку Network на статус запросов
4. Убедитесь что backend и AI-сервис запущены

### Кнопка "Полный отчет" не появляется

**Причина:** Анализ еще не выполнен

**Решение:**
1. Выберите вакансию
2. Нажмите "Запустить AI-анализ"
3. Дождитесь завершения
4. Кнопка появится автоматически

### Экспорт CSV не работает

**Решение:**
- Проверьте настройки браузера (разрешены ли загрузки)
- Попробуйте другой браузер
- Проверьте что в результатах есть данные

## 🎯 Часто задаваемые вопросы

### Можно ли анализировать без интернета?

**Да!** Система работает полностью локально. ML модели загружаются один раз при установке.

### Сохраняются ли результаты анализа?

**Да!** Результаты с оценкой ≥4.0 автоматически сохраняются в базу данных и доступны на вкладке "Дашборд".

### Можно ли изменить критерии оценки?

**Да!** Настройте в `ai/config.py`:
- Веса компонентов (навыки, семантика, опыт, образование)
- Пороги категорий
- Синонимы навыков

### Понимает ли система синонимы?

**Да!** 100+ встроенных синонимов:
- Python = Python3 = питон
- JavaScript = JS = ES6
- Kubernetes = K8s
- PostgreSQL = Postgres

### Как система определяет опыт?

Автоматически извлекает из резюме паттерны:
- "5 лет опыта"
- "Опыт работы: 3 года"
- "3+ years of experience"
