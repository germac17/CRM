# Как загрузить файлы на Beget

## Способ 1: Файловый менеджер Beget

1. В панели Beget откройте **«Файловый менеджер»** или **«Файлы»** в левом меню.
2. Перейдите в директорию сайта (например, `public_html` или `naymi.tech`).
3. Нажмите **«Загрузить»** или **«Upload»**.
4. Выберите файлы с компьютера или перетащите их в окно браузера.
5. Загрузите **все файлы и папки** из `frontend/dist/`:
   - `index.html` — в корень
   - папка `assets/` — целиком

## Способ 2: FTP (FileZilla, WinSCP)

1. Установите **FileZilla** (https://filezilla-project.org) или **WinSCP**.
2. В панели Beget найдите данные FTP:
   - **«Файловый менеджер»** → **«Доступ по FTP»** или **«Учётные записи FTP»**
   - Там будут: хост, логин, пароль
3. Подключитесь к серверу:
   - Хост: `ваш-сайт.beget.ru` или IP из панели
   - Логин и пароль — из панели Beget
4. Перейдите в папку сайта (например, `public_html`).
5. Перетащите содержимое папки `frontend/dist/` в окно удалённого сервера.

## Способ 3: Архив через панель

1. На компьютере:
   - Соберите проект: `npm run build`
   - Заархивируйте содержимое папки `frontend/dist/` в ZIP (не саму папку dist, а её содержимое).
2. В панели Beget:
   - Откройте **«Файловый менеджер»**.
   - Загрузите ZIP-архив.
   - Распакуйте его в нужной директории (обычно есть кнопка «Распаковать»).

---

## Что именно загружать

После команды `npm run build` в проекте появится папка `frontend/dist/`:

```
frontend/dist/
├── index.html      ← главная страница
└── assets/         ← файлы JS, CSS
    ├── index-xxxxx.js
    ├── index-xxxxx.css
    └── ...
```

Загрузите **всё содержимое** папки `dist/` (включая `index.html` и `assets/`) в корень сайта на Beget.

---

## Важно

- **index.html** должен быть в корне сайта (например, `public_html/index.html`).
- Папка **assets** — рядом с `index.html`.
- Если на Beget уже есть файлы — можно заменить их новыми или удалить старые перед загрузкой.
