## 🐛 Troubleshooting

### Проблема: Frontend не видит AI-сервис

**Решение:**
1. Проверьте, что AI-сервис запущен:
   ```powershell
   curl http://localhost:8001/health
   ```

2. Проверьте CORS в `ai/app.py`:
   ```python
   app.add_middleware(
       CORSMiddleware,
       allow_origins=["*"],  # Или конкретный домен
   )
   ```

### Проблема: "Вакансия не найдена" в AI-сервисе

**Причина:** AI-сервис читает из `backend/data/`

**Решение:**
1. Убедитесь, что backend запущен
2. Создайте вакансию через UI
3. Проверьте файл: `backend/data/user-usr-admin-vacancies.json`

### Проблема: Результаты не отображаются

**Решение:**
1. Откройте DevTools (F12)
2. Проверьте Console на ошибки
3. Проверьте Network вкладку
4. Убедитесь что ответ от API корректный
