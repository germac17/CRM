# Что передать в поддержку Beget для развёртывания naymi.tech

## Файлы для тикета

Приложите к тикету в поддержку Beget **два файла**:

| Файл | Описание |
|------|----------|
| **naymi-tech-deploy.zip** | Архив со статическим сайтом (готов к распаковке) |
| **ИНСТРУКЦИЯ_ДЛЯ_BEGET.txt** | Краткая инструкция для специалиста |

---

## Текст для тикета (скопируйте)

```
Тема: Развёртывание статического сайта на домене naymi.tech

Добрый день!

Прошу развернуть статический сайт (HTML, CSS, JavaScript) на домене naymi.tech.

Прилагаю:
1. naymi-tech-deploy.zip — архив с файлами сайта
2. ИНСТРУКЦИЯ_ДЛЯ_BEGET.txt — инструкция по развёртыванию

Домен naymi.tech должен быть добавлен в раздел «Домены и поддомены».

Спасибо!
```

---

## Что внутри архива

- **index.html** — главная страница
- **assets/** — скрипты и стили (JS, CSS)
- **.htaccess** — настройка SPA (перенаправление на index.html)

Архив уже готов к распаковке в `public_html` или корень сайта.

---

## Перед отправкой

1. Убедитесь, что домен **naymi.tech** добавлен в панели Beget (раздел «Домены и поддомены»).
2. Запустите `.\prepare_deploy.ps1` для создания свежего архива (если вносили изменения в проект).
3. Приложите оба файла к тикету.

---

## Важно

Это **статический фронтенд** (React SPA). Вход и API будут работать только при наличии backend на хостинге с Node.js. На обычном Beget отобразится интерфейс, но без авторизации и данных.
