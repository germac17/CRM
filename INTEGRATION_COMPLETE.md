## 🚀 ЗАПУСК (3 способа)

### Способ 1: Автоматический (РЕКОМЕНДУЕТСЯ!)

```powershell

```

### Способ 2: Docker

```powershell
docker-compose up -d
```

### Способ 3: Вручную

```powershell
# Терминал 1
cd backend && npm run dev

# Терминал 2
cd ai && python app.py

# Терминал 3
cd frontend && npm run dev
```
