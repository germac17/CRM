# Как привязать naymi.tech к сайту в Beget

## Проблема
Сообщение «Домен не прилинкован ни к одной из директорий на сервере» означает, что домен naymi.tech пока не связан ни с одним сайтом.

## Что сделать

### Шаг 1. Откройте раздел «Сайты»
В левом меню панели Beget найдите раздел **«Сайты»** (или «Сайт» / «Хостинг») и откройте его.

### Шаг 2. Добавьте сайт или выберите существующий
- Если сайтов ещё нет — создайте новый сайт.
- Если сайт уже есть — откройте его настройки.

### Шаг 3. Привяжите домен naymi.tech к сайту
В настройках сайта найдите пункт **«Домены»** или **«Привязать домен»** и добавьте `naymi.tech` к этому сайту.  
После этого домен будет указывать на директорию сайта (например, `public_html` или `naymi.tech`).

### Шаг 4. Загрузите файлы приложения
В директорию сайта (обычно `public_html` или `домен.tech`) загрузите:
1. Содержимое папки `frontend/dist/` (после `npm run build`)
2. Либо настройте прокси на backend (если Beget поддерживает Node.js)

---

## Важно: Beget и Node.js

Beget — это в основном хостинг для PHP и статических сайтов. **Node.js на обычном тарифе может не поддерживаться.**

### Вариант А: Только статика (без backend)
Если Node.js недоступен, можно:
1. Собрать фронтенд: `npm run build`
2. Загрузить содержимое `frontend/dist/` в `public_html`
3. Настроить API на другом сервере (VPS, Railway, Render и т.п.) и указать его URL в `VITE_API_URL`

### Вариант Б: VPS с Node.js
Для полной работы приложения (frontend + backend + AI) нужен сервер с Node.js, например:
- VPS (Timeweb, Selectel, DigitalOcean)
- Railway, Render, Fly.io

---

## Краткая схема

```
Панель Beget → Сайты → [Ваш сайт] → Домены → Добавить naymi.tech
```

Если в меню нет раздела «Сайты», поищите «Хостинг», «Файловый менеджер» или «Управление сайтами».
