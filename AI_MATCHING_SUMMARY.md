└─────────────────────────────────────────────────────────────┘

### 🧠 Алгоритм матчинга

**Компоненты оценки:**

1. **Навыки (40%)** ✅
   - Точное совпадение с учетом синонимов
   - Must-have vs Nice-to-have
   - 100+ встроенных синонимов

2. **Семантическое сходство (30%)** ✅
   - TF-IDF векторизация
   - BERT embeddings (multilingual)
   - Cosine similarity

3. **Опыт работы (20%)** ✅
   - Автоматическое извлечение из резюме
   - Сравнение с требованиями
   - Учет over/under qualified

4. **Образование (10%)** ✅
   - Распознавание уровня образования
   - Соответствие требованиям

**Итоговая оценка: 1-10 баллов с прозрачным объяснением**

### 🎨 Категоризация

- 🟢 **Подходящие (7-10)** - Рекомендуем к собеседованию
- 🟡 **Условно подходящие (4-6)** - Рассматриваем
- 🔴 **Не подходящие (1-3)** - Отклоняем

### 📊 API Endpoints

Полностью работающий REST API:

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/health` | GET | Проверка здоровья |
| `/api/match/analyze` | POST | Анализ одного кандидата |
| `/api/match/batch` | POST | Массовый анализ |
| `/api/match/top/{id}` | GET | Топ N кандидатов |
| `/api/parse/resume` | POST | Парсинг резюме (текст) |
| `/api/parse/file` | POST | Парсинг PDF/DOCX |
| `/api/stats` | GET | Статистика системы |

**Интерактивная документация:** http://localhost:8001/docs

### 🔧 Фильтры и настройки

**Типы фильтров:**
- `must_have` - обязательные требования (штраф при несоответствии)
- `nice_to_have` - желательные навыки (бонус при наличии)
- `dealbreakers` - исключающие факторы (сильный штраф)

**Операторы:**
- `contains` - содержит навык
- `any_of` - любой из списка (Python|Java|Go)
- `>`, `<`, `=` - для числовых значений

**Веса:** 1-5 (настраиваются для каждого критерия)

### 📝 Парсинг резюме

**Поддерживаемые форматы:**
- ✅ Текст (plain text)
- ✅ PDF (через PyPDF2)
- ✅ DOCX (через python-docx)

**Извлекаемые данные:**

- Достижения (achievements)
